# Pool Patcher
Pool Patcher was a program I built on my own, while working at a company to help improve certain tasks which were very tedious for a person, but very simple for a program to do.
This program was essentially a method to host and manage a framework to be able to develop tools, which would then be accessible from a webpage.

# Functionality
In its current form, the website only works on chrome + edge, and tends to be buggy on Firefox. One day I'll revisit some of the code to make it work better though.
